# CARBU-TRACKER

Suivi personnel de l'évolution des prix des carburants dans les stations-service de
**Vannes** et **Séné** (Morbihan).

Sélectionner une station + un carburant → voir la courbe historique des prix et les tendances.

Données issues de l'open data français sur les prix des carburants (voir [docs/DATA-SOURCE.md](docs/DATA-SOURCE.md)).
